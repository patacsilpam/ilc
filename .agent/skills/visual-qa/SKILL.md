# Visual QA Skill

## Review
- Compare implemented screens with `DESIGN_SYSTEM.md`.
- Inspect mobile widths, desktop CMS widths, long text, empty data, loading, and errors.
- Check image aspect ratios, crop behavior, safe areas, and broken assets.
- Check contrast, focus states, keyboard access, touch targets, and labels.
- Verify status meaning is not communicated by color alone.
- Remove accidental template styling and generic AI-dashboard patterns.

## Reference handling
The supplied VMX screenshot is inspiration for feature-led visual storytelling only. Do not copy its logo, brand language, text, or exact screen design. Build an original ILC interface.
